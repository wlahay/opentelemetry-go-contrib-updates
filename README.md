# OpenTelemetry-Go Contrib Updates

This repository is used to share program updates, maintenance plans,
and project announcements related to OpenTelemetry-Go Contrib.

## Purpose

- Share updates on maintenance work and compatibility improvements
- Document planned support for new Go framework and cloud SDK versions
- Publish release notes, security updates, and contributor announcements
- Provide a durable record of project activity for users and sponsors

## Update cadence

Updates will be added at least monthly, with additional posts for
security fixes, major releases, or important ecosystem changes.

## Contact

For security issues, please follow the project's responsible-disclosure
process. Do not open public issues containing sensitive details.
